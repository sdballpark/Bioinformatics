# 🧬 Machine Learning in Bioinformatics: Tools, Repos & Notebooks

Explore open-source tools, repositories, and Python libraries used to solve bioinformatics problems using machine learning and AI. Ideal for researchers, data scientists, and computational biologists.

## 🔬 Python Libraries for Bioinformatics + ML

These libraries are optimized for omics data, statistical testing, single-cell analysis, and ML-driven bioinformatics workflows.

| Library | Use Case | Link |
|---------|----------|------|
| 🧬 **Biopython** | Core library for sequence analysis, FASTA/GenBank parsing. | [Website](https://biopython.org/) |
| 🔬 **Scanpy** | Scalable single-cell RNA-seq analysis. | [Docs](https://scanpy.readthedocs.io/en/stable/) |
| 📊 **scvi-tools** | Probabilistic modeling for single-cell data using PyTorch. | [Website](https://scvi-tools.org/) |
| 🧠 **gseapy** | Pythonic gene set enrichment analysis (GSEA). | [Docs](https://gseapy.readthedocs.io/en/latest/) |
| 📈 **pydeseq2** | DESeq2 RNA-seq differential expression in Python. | [Docs](https://pydeseq2.readthedocs.io/en/latest/) |
| ⚗️ **mlpy** | Machine learning toolkit suited for bio data classification. | [Website](http://mlpy.sourceforge.net/) |
| 🍊 **Orange3 Bioinformatics** | Drag-and-drop GUI for data analysis with bioinformatics add-ons. | [GitHub](https://github.com/biolab/orange3) |
